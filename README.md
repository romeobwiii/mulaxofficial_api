*🛠 Installation  *
Get started with *Mulax API* in seconds!  

```bash
npm install mulax-api
```

or using *Yarn* :  

```bash
yarn add mulax-api
```



*🎯 Usage Example  *
Make your first API request!  

```javascript
import { fetchData } from 'mulax-api';

async function getData() {
    const response = await fetchData('https://api.mulax.com/data');
    console.log(response);
}

getData();
```
